Chaotic Pedalboard

nara is neus and Spacebarman (2026)
Audience-controlled networked guitar pedalboard
Chaotic Pedalboard is half an installation, half a performance, and consists of a set of guitar effects pedals (a pedalboard) that have been connected to the Internet. A near-real-time server allows pedals to be controlled remotely from the network. This lets people attending the event take control of the effects, collaboratively transforming the guitar's final sound. The audience can also contribute to the performance by using their phones as synthesizers (no app installation required).
